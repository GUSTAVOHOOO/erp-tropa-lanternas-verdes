# API NestJS de referência

Exemplo completo, em domínio neutro, testado com NestJS 12.4, TypeORM 1.1 e PostgreSQL. Use só ao criar uma API do zero; em código existente, mantenha rotas e formato de resposta do projeto.

Passou em 35 testes de ponta a ponta: validação, envelope, autenticação, papéis, dono do recurso, rollback e concorrência.
