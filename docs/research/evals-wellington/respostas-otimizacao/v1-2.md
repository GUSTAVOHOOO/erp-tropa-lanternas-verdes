# Propostas

## C1 — Revisão de atribuição

A action deve exigir papel no servidor, validar entrada como `unknown`, usar `parsed.data` e deixar `redirect` fora do `try`. O proxy não substitui a autorização da própria Server Action.

```ts
'use server'

import * as z from 'zod'
import { redirect } from 'next/navigation'
import { revalidatePath } from 'next/cache'
import { exigirPapel } from '@/lib/dal'
import { atribuicaoSchema } from '@/lib/schemas/ocorrencia'
import { atribuirResponsavel } from '@/lib/ocorrencias'
import type { ResultadoAcao } from '@/lib/resultado-acao'

export async function atribuir(dados: unknown): Promise<ResultadoAcao> {
  await exigirPapel('guardiao') // [AUTH-05]

  const parsed = atribuicaoSchema.safeParse(dados) // [FORM-17]
  if (!parsed.success) {
    return { ok: false, errors: z.flattenError(parsed.error).fieldErrors } // [FORM-18]
  }

  try {
    await atribuirResponsavel(parsed.data.id, parsed.data.responsavelId)
  } catch {
    return { ok: false, erro: 'Não foi possível atribuir.' }
  }

  revalidatePath('/painel/ocorrencias')
  redirect('/painel/ocorrencias') // [ROTA-20]
}
```

## C2 — Lista privada

No Next 16, `searchParams` é uma Promise. A página verifica a sessão e calcula o filtro no servidor; `setorParaFiltro` prende Lanternas ao setor da sessão, independentemente da URL.

```tsx
// app/(painel)/painel/ocorrencias/page.tsx
import { verificarSessao } from '@/lib/dal'
import { setorParaFiltro } from '@/lib/sessao'
import { listarOcorrencias } from '@/lib/ocorrencias'
import { EstadoVazio } from '@/components/estado-vazio'
import { ListaOcorrencias } from '@/components/lista-ocorrencias'

type Props = {
  searchParams: Promise<{ setor?: string }>
}

export default async function Pagina({ searchParams }: Props) {
  const sessao = await verificarSessao() // [AUTH-04]
  const filtros = await searchParams // [ROTA-10]
  const setorId = setorParaFiltro(sessao, filtros.setor) // [AUTH-07]
  const itens = await listarOcorrencias({ setorId })

  if (itens.length === 0) {
    return <EstadoVazio mensagem="Nenhuma ocorrência para este filtro." />
  }

  return <ListaOcorrencias itens={itens} />
}
```

Os imports dos componentes de estado/lista são ilustrativos, pois seus contratos não foram fornecidos. A rota deve cobrir: carregamento (por exemplo, `loading.tsx` com skeleton), vazio (mensagem e ação útil, como limpar filtros), erro (em `error.tsx`, mensagem humana e opção de tentar novamente) e sucesso (itens). A chamada ao serviço deve tratar falhas conforme o contrato do projeto. Regras: [AUTH-04], [AUTH-07], [ROTA-10], [API-09].
