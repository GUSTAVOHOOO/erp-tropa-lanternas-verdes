# Lanternas Verdes: Grupo D (6 personagens)

Continuidade: principal atual da DC (Terra-0). Data de 2026-11-06.

## Nota de método

- As páginas de personagem do fandom (dc.fandom.com) devolveram HTTP 402, e as páginas diretas de dc.com e comics.org devolveram HTTP 403. Por isso, os dados marcados como `verificado` vêm dos trechos de busca de dc.com e comics.org (WebSearch restrito a esses domínios), com a URL da página que aparece no resultado. Isso está registrado em Pendências.
- Dados bibliográficos (título, número, data de capa) vêm do Grand Comics Database (comics.org). Quando a edição do GCD lista o personagem no elenco, a estreia é tratada como confirmada. Quando a estreia exigia uma página que não abriu, o campo ficou `não verificado`.
- Wikipedia e fandom foram usados só para descobrir o que conferir. Nada da Wikipedia ou do fandom está marcado como `verificado`.
